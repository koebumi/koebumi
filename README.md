# Koebumi

日本語 | [English](README.en.md) | [简体中文](README.zh-CN.md)

[Webサイト](https://koebumi.github.io)で、動く見本を見られます。

https://github.com/user-attachments/assets/0e4b7786-0596-448b-9914-9a02559e7bd7

Koebumiは、macOSで使う音声入力アプリです。どのアプリでもFnキーを押して話すと、言いよどみや言い直しを取り除いた文章をカーソル位置に入力します。力を入れているのは、日本語の書き言葉に仕上げることと、Claude Code・Codexに声で指示できることです。無料で、ソースコードも公開中です。

日本語の仕上がりでは、句読点や表記を決まった規則でそろえます（〜して下さい → 〜してください、三時 → 3時）。くだけた話し方をしても、ビジネス敬語に直せます。人名の書き方は、画面に出ている表記が基準です。

Claude CodeとCodexは、声で操作できます。「スラッシュ コンパクト」と話すと/compactを入力し、許可の確認には「はい」や「いいえ、先にビルドだけして」と答えられます。文の最後に「送信」と言った場合は、Enterキーを押すところまでが自動です。話したファイル名は、作業フォルダにある実際の表記に直します。

https://github.com/user-attachments/assets/a5920796-f5ec-4649-aba0-fd8be5227bf1

APIキーがなくても使えます。その場合は、Appleのオンデバイスモデルや、このMacで動かす音声認識モデルを使うので、処理する場所はこのMacの中です。履歴・音声・辞書の保存先も、このMacの中だけです。

手持ちのAIで整形することもできます。ClaudeやOpenAI互換APIのキーのほか、ClaudeやChatGPTのサブスク（Claude Code・Codex経由）も使えます。

## 入れ方

必要な環境は、macOS 26以降のAppleシリコンのMacです。

1. [Releases](https://github.com/koebumi/koebumi/releases/latest)から`Koebumi-<版>.zip`をダウンロードして開く
2. 出てきたKoebumi.appを「アプリケーション」フォルダに入れて開く
3. 「開けませんでした」と出たら「完了」を押す。続けて、システム設定 > プライバシーとセキュリティを開き、下のほうにある「Koebumi」の「このまま開く」を押す
4. セットアップ画面に沿って、マイクとアクセシビリティを許可し、Fnキー（地球儀キー）を押したときの動作を変える

3の操作が必要なのは、まだAppleの公証を受けていないためで、行うのは最初の1回だけです。新しい版が出たときは、Koebumiが知らせます。Appleのオンデバイスモデルで整形するには、Apple Intelligenceをオンにしてください。

## 使い方

| 操作 | 既定のショートカット | 内容 |
|---|---|---|
| ディクテーション | `Fn` | 短く押すとハンズフリーになり、もう一度押すと確定します。押し続けて話すと、離したときに確定します（プッシュトゥトーク） |
| 翻訳 | `Fn + Left ⇧` | 話した内容を、翻訳先の言語で入力します。翻訳先は音声バーで切り替えられます |
| Ask anything | `Fn + Space` | テキストを選択してから「もっと丁寧に」などと話すと書き換えます。質問にはカードで答え、「YouTubeで猫の動画」のような依頼ならページを開きます |
| 最後の結果を貼り付け | `Left ⌥ + Left ⌘ + V` | 直前の結果を、もう一度カーソル位置に入力します。キーをすべて離したときに貼り付けます |
| キャンセル | `Esc` | 録音や処理を止めます。回答カードも閉じます |

Fnを押したまま話している途中でShiftやSpaceを足すと、録音を続けたまま翻訳やAskに切り替わります。ショートカットは設定画面で変更でき、1つの操作に複数を登録することも可能です。

Finder（デスクトップ）で入力欄にフォーカスがないときに話すと、結果を貼り付けずにクリップボードにコピーします。

## できること

| 機能 | 内容 |
|---|---|
| 整形 | 言いよどみ・繰り返し・言い直しを取り除きます。列挙は箇条書きにし、「改行」「新しい段落」と話すと改行します |
| 日本語の表記 | 句読点の種類や、英単語の前後に空白を入れるかを選べます。「〜して下さい」「〜する事」は「〜してください」「〜すること」と書きます |
| アプリごとの文体 | 入力先のアプリを6種類に分け、種類ごとに文体（ビジネス敬語など）を選べます。チャットに分類したアプリでは、既定で句読点を付けません |
| Claude Code・Codex | スラッシュコマンドの入力、許可の確認への返事、ファイル名の表記の修正、「送信」でのEnterに対応しています |
| 辞書 | 単語と、その単語の「聞き取られ方」を登録できます。入力してから1分以内に直した単語は、自動で辞書に入ります |
| 文体の学習 | 6回話すごとに、丁寧さや言い回しの癖を学習します。話した内容そのものは保存しません |
| 翻訳・Ask | 話した内容を翻訳して入力します。選択したテキストの書き換えや、質問への回答もできます |
| 履歴・統計 | 履歴の検索や再処理、録音のダウンロードができます。話した単語数や、節約した時間も記録します |

詳しい説明は、[機能の説明](docs/features.md)にあります。

## AIエンジン

APIキーがなくても、Appleのオンデバイスモデルで使えます。エンジンを選ぶのは、設定 > AIエンジン の画面です。

| 用途 | 選べるもの |
|---|---|
| 音声認識 | Apple（既定）、このMacで動かすモデル（Qwen3-ASR・Whisperなど5種類）、OpenAI、Groq、OpenAI互換のサーバー |
| 整形・翻訳・Ask | Apple（既定）、Claude、Claudeのサブスク（Claude Code経由）、ChatGPTのサブスク（Codex経由）、OpenAI互換（OpenAI・Groq・OpenRouter・Gemini・Ollamaなど） |

モデルごとの速さや違いも、[機能の説明](docs/features.md)にまとめています。

## プライバシー

- 履歴・録音・辞書・学習内容は、このMacの中にだけ保存します。APIキーはキーチェーンに保存します
- クラウドのエンジンやサブスクのエンジンを選んだときは、録音または書き起こした文章を、選んだサービスに送ります
- 画面の文脈（入力欄の前後や、画面に出ている人名・用語）は、既定ではこのMacの中で整形するときだけ使います。読んだ内容は保存しません
- 新しい版を確かめるため、1日1回GitHubにアクセスします。設定 > 一般 でオフにできます

## 主な制限

- Appleのオンデバイスモデルは小型なので、複雑な言い直しや翻訳、Askでの書き換えはClaudeなどに劣ります。1,000字以上の長い発話は、整形に10〜20秒ほどかかります
- サブスクのエンジンは、Claude Code・Codexと同じ利用枠を使います。Koebumiはログインのトークンに触れず、このMacのClaude Code・Codexを起動するだけです。ただし、各社が他社のアプリ向けに用意した仕組み（OpenAIのSign in with ChatGPTなど）は使っていません。そのため、AnthropicやOpenAIの規約や方針が変わると、使えなくなったり別料金になったりすることがあります
- 表示言語は日本語と英語だけです
- 画面の文脈は、アクセシビリティAPIで文字を公開しているアプリでだけ使えます

ほかの制限は、[機能の説明](docs/features.md#制限事項)にあります。
